# Setup

Sources: S-OFF Setup, Variants; S-RU Подготовка к игре.

1. **R-SETUP-01** Shuffle the treasure, loot and monster decks; each gets a discard pile next to it.
2. **R-SETUP-02** The game's ¢ pool holds at least 100¢; it never runs out in practice.
3. **R-SETUP-03** Reveal the top 2 treasure cards into 2 shop slots; they are the starting shop items.
4. **R-SETUP-04** Reveal the top 2 monster cards into 2 monster slots.
5. **R-SETUP-05** An event revealed during setup goes to the bottom of the monster deck and is replaced; repeat until both slots hold monsters.
6. **R-SETUP-06** With bonus souls: shuffle them and pick 3 at random as the active bonus souls; place them face up beside the play area.
7. **R-SETUP-07** Each player gets a random character card and that character's starting item.
8. **R-SETUP-08** Characters start deactivated; starting items start charged.
9. **R-SETUP-09** Abilities that trigger at the start of the game resolve at once, without priority (e.g. Eden's choice).
10. **R-SETUP-10** Each player gets 3 loot cards into their hand and 3¢.
11. **R-SETUP-11** The starting player is chosen by any fair random method; the official text suggests the lowest dice roll. We roll (GS-06).
12. **R-SETUP-12** *(later sets)* With the room deck: shuffle it and reveal the top card into a room slot.
13. **R-SETUP-13** There is no mulligan in the official rules.
14. **R-SETUP-14** Variant *Mini-draft* (recommended for 2 players): reveal (players + 1) treasure cards; players pick one each in turn order, the rest go to the bottom; second round picks in reverse order. Each player ends with 2 extra items.
15. **R-SETUP-15** Variant *Eden Only*: every player is dealt Eden instead of a random character.
