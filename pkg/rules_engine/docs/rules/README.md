# Four Souls rules (our text)

Our own wording of the rules of The Binding of Isaac: Four Souls (R-04).
The engine implements these rules; tests and sandbox answers cite their IDs.

## Rule IDs

1. Form: `R-<TOPIC>-<NN>`, e.g. `R-STACK-03`.
2. IDs are stable: never renumber, never reuse.
3. New rules are appended with the next free number.
4. A removed rule keeps its ID and is marked *Withdrawn*.
5. A test checks every ID is unique and well formed.
